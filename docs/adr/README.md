# Architecture Decision Records

This folder holds the Architecture Decision Records (ADRs) for SSW.Rules, managed with [Log4brains](https://github.com/thomvaill/log4brains).

## Development

If not already done, install Log4brains:

```bash
npm install -g log4brains
```

To preview the knowledge base locally, run this from the repository root:

```bash
log4brains preview
```

In preview mode, any change you make to a markdown file is applied live in the UI.

To create a new ADR interactively, run:

```bash
log4brains adr new
```
